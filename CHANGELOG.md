## 1.0.0+1

- Initial release of **ff_chat** 🎉
- Added core chat UI with:
  - Text, image, video, and file messaging
  - Message status indicators (sent, uploading, failed)
  - Firebase Firestore backend integration
  - Firebase Storage media uploads
  - Typing indicator and presence via Realtime Database

- Included a working `example/` app for testing and setup.
